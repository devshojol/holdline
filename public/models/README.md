# Soldiers (`agents/`)

The soldiers players pick in multiplayer (`src/game/agents.ts`); bots wear a random one, in multiplayer and in
practice, when **Settings → Graphics → Bot model** is set to *Agents* (the default). A missing or broken file falls
back to the built-in blocky body in that soldier's colours. The models have no animations of their own: the game
poses their skeletons in code (`src/game/bots/AgentVisual.ts`).

There are ten: Ranger, Shade, Dune, Slate, Tide, Frost, Ember, Grove, Flint and Moss, each with their own face,
hair, headgear (helmet, cap, beanie or headset) and camouflage. `tools/blender/make_bots.py` builds them
(`python3 tools/blender/bl.py tools/blender/make_bots.py` with Blender open and the MCP for Blender addon's
server started):

- **Body, face, hair, clothes, boots and skeleton** are generated by MPFB, the MakeHuman add-on for Blender
  (<https://extensions.blender.org/add-ons/mpfb/>), from its "MakeHuman system assets" pack, which is **CC0**.
  The add-on itself is GPL, which covers the tool, not what it makes. The script renames the skeleton's joints
  to the ones the game poses and adds the eye joints.
- **Camouflage, plate carrier, pouches, belt, knee pads, holster and headgear** are our own: generated and
  modelled from code, and fitted to each body's measurements.

`agents/portraits/<id>.webp` are head-and-shoulders renders made by the same script.

# Guns (`weapons/`)

Used for the first-person guns when **Settings → Graphics → Gun models** is set to *Skins* (the default);
the bots carry the Kestrel. A missing or broken file falls back to the simple built-in gun.

All eight are our own designs, modelled from code in Blender by `tools/blender/make_weapons.py`
(run it with `python3 tools/blender/bl.py tools/blender/make_weapons.py` while Blender is open with the
MCP for Blender addon's server started). No third-party assets, so no credits or licence terms apply.

| File | Gun | Moving parts |
| --- | --- | --- |
| `vandal.glb` | Kestrel, assault rifle | `mag` |
| `phantom.glb` | Halcyon, suppressed rifle | `mag` |
| `spectre.glb` | Hornet, SMG | `mag` |
| `guardian.glb` | Arbiter, marksman rifle | `mag` |
| `operator.glb` | Monarch, bolt-action sniper | `mag`, `bolt` |
| `classic.glb` | Pilot, pistol | `mag` |
| `ghost.glb` | Whisper, suppressed pistol | `mag` |
| `sheriff.glb` | Magnate, revolver | `cylinder` |

The file names still use the old internal weapon ids; they are to be renamed with the ids.
The script also writes the grip, handguard, muzzle and sight points used by
`src/game/weapons/WeaponSkins.ts` to `tools/blender/out/specs.json`, with a preview image per gun.

# First-person arms (`fp-arms.glb`)

Used for the player's arms when **Settings → Graphics → First-person arms** is set to *Rigged arms*, and as the fallback
when the animated arms can't load. If the file is missing or isn't the expected model, the game uses its built-in arms
(simple shapes, no file needed).

by [Exactly](https://sketchfab.com/txyrm70), licensed under [CC BY 4.0](http://creativecommons.org/licenses/by/4.0/).

## Changes made to the original

- Textures converted from PNG to WebP (`gltf-transform webp --quality 82`, then `prune`): 4.2 MB → 1.1 MB.
- The file itself is otherwise unchanged. The model has no skeleton, so `src/game/weapons/ArmModel.ts` cuts out the
  two arms when it loads and skins them in code (forearm, hand, three joints per finger and thumb), using joint
  positions measured on this file.

# Animated first-person arms (`fp-arms-anim.glb`)

Used for the player's arms when **Settings → Graphics → First-person arms** is set to *Animated* (the default).
They play the pack's own draw, fire and reload animations with the game's rifles attached. Sidearms use the
pistol arms below; without that file, these arms are posed onto the pistol instead. If this file is missing or
isn't the expected pack, the game falls back to `fp-arms.glb`, then to its built-in arms.

## Credit (CC BY 4.0)

"[M4 - FPS Weapon Animations Pack (v.1)](https://sketchfab.com/3d-models/m4-fps-weapon-animations-pack-v1-662fc74dda2646cfb48fc610705768ef)"
by [BarcodeGames](https://sketchfab.com/barcodegames), licensed under [CC BY 4.0](http://creativecommons.org/licenses/by/4.0/).

## Changes made to the original

Made with `scripts/prepare-fp-arms.mjs` (11.5 MB → 1.1 MB):

- materials converted from specular/glossiness to metal/roughness,
- the M4 rifle, its magazines, bullets, bolt, trigger and safety lost their meshes (their joints and all
  animations are kept; the game attaches its own guns to the weapon joint and moves its own magazine with the
  pack's magazine joints),
- textures resized to at most 1024 px and converted to WebP,
- unused data pruned.
